# mercurius-browser-service

**English** | [Русский](README.ru.md)

A browser service for the agent: Chrome driven by Puppeteer behind an HTTP API on Fastify, shipped as a Docker image. Keeps persistent browser profiles so the agent can work with web interfaces.

Part of [Mercurius](https://github.com/opencck/mercurius) — an autonomous personal agent. The package does not depend on the Mercurius application and can be used on its own.

**Status:** planned, no code yet.

**Stack:** Node.js, Docker.
