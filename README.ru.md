# mercurius-browser-service

[English](README.md) | **Русский**

Сервис браузера для агента: Chrome под управлением Puppeteer за HTTP API на Fastify, поставляется Docker-образом. Хранит постоянные профили браузера, чтобы агент мог работать с веб-интерфейсами.

Часть проекта [Меркурий (Mercurius)](https://github.com/opencck/mercurius) — автономного персонального агента. Пакет не зависит от приложения Меркурия и может использоваться отдельно.

**Статус:** не используется. Сервис браузера Меркурия живёт в [`mercurius-browser`](https://github.com/opencck/mercurius-browser) — отдельном модуле.

**Стек:** Node.js, Docker.
